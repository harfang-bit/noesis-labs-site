Local Python utility

Remove duplicate lines. Keep the original order.

Text Deduper keeps the first occurrence of each exact line and removes later duplicates. It runs locally on your computer; your text does not need to be uploaded to a cloud service.

What it does

  • Exact-line deduplication while preserving input order
  • Handles LF and CRLF line endings
  • Handles empty input and repeated lines
  • Supports Unicode and non-ASCII text
  • Treats literal \n text separately from actual line breaks

Requirements

Python 3.12 or a compatible Python 3 environment. The utility is intended to run locally.

What you receive

A downloadable local software utility and usage instructions for exact-line deduplication.
